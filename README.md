# Skyrim to VRC Conversion
Compendium of scripts, programs, and guides to convert a character in Skyrim SE over to VR Chat, or a usable FBX for usage wherever..

## AI Usage Disclaimer: 
The Python scripts are coded from ChatGPT. Python is beyond me, and I really didn't want to learn a whole scripting API just for this project.
Most of the Java code is AI-assisted, not totally AI generated. Unlike the Python, which was fully "vibe coded". 
Since I do have a solid understanding of Java (just look at my previous repositories) as opposed to Python, the AI was mostly used for implementation, debugging and nudges in the right direction.

However, the guide and entire process was written by, and figured out by me. Credit to a good friend who helped on the phenome to viseme mapping.

# Requirements:

# What's in this thing?
- Tri Toolkit. Allows one to extract both facegen tris, and bodyslide tris.
- A bunch of Blender scripts that are generally named after what they do, with some comments within each script.
- A locally ran HTML page containing a detailed guide. (Not yet Started)
- A program to load your RaceMenu preset and it should dump all the content related to your character. (In Progress)
